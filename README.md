# Jobby-App

Job search web app built with React JS, React Router, JWT authentication and Bootstrap.

## Features
- Login with JWT stored in a cookie; protected routes redirect to /login
- Jobs list with search, employment-type (multi) and salary-range filters
- Job details page with skills, life at company and similar jobs
- Loading, empty, error and retry states for every API call

## Run
```
npm install
npm run dev
```
Test login: username `rahul`, password `rahul@2021` (NxtWave Jobs API).

## Tech
React 18 (class components), react-router-dom v5, js-cookie, Bootstrap 5, Vite.
